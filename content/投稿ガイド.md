# TikTok 手動投稿ガイド

## 投稿前の準備チェックリスト

- [ ] TikTokプロフィールを「教育」カテゴリに設定
- [ ] bio に「毎日21時 心理クイズ投稿中🧠」などを追加
- [ ] アカウント名は覚えやすく心理系と分かる名前にする

---

## 動画ごとの投稿手順

### Step 1: quiz-data.json を差し替える

`public/quiz-data.json` を当日分のファイルに差し替えて、Windowsターミナルでレンダリング：

```bash
# 例：Day1の場合
copy content\day1_行動心理.json public\quiz-data.json
node scripts\render.mjs
# → output\quiz-YYYY-MM-DD.mp4 が生成される
```

### Step 2: TikTokアプリで投稿

1. 生成された `.mp4` をスマートフォンに転送
2. TikTokアプリで「+」→「アップロード」
3. **音楽を追加**（人気の楽曲をここで付ける）
4. キャプションを貼り付け（下記テンプレート参照）
5. 投稿時間：**21:00 JST** を目安に

## バズった動画の分析ポイント

最初の10本を投稿したら以下を確認：
- **視聴完了率** → 50%以上なら合格、70%以上なら優秀
- **保存数** → いいねの10%以上あれば優良コンテンツ
- **コメント** → どのカテゴリに「あるある！」反応が多いか
- **フォロー転換率** → 再生数に対してフォロワーが増えているか

伸びているカテゴリを増やし、伸びていないカテゴリは内容を変える。
